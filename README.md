# Kor_History_Test

한능검 오답노트 퀴즈 사이트.

- `index.html`: 퀴즈 사이트 (서버 없이 브라우저에서 바로 열기)
- `data.txt`: 학습 자료 원본 (`용어: 설명, 설명, ...` 형식, `[고구려]` 같은 헤더로 구역 구분)
- `materials/`: 학습 자료 txt 파일을 추가로 넣는 폴더
- `bank.js`: 한능검 형식 문제 은행 (대상별 서술문, 연표 사건). 문제를 늘리려면 여기에 추가
- `build.py`: `data.txt`와 `materials/*.txt`를 읽어 `index.html`에 내장

## 자료를 고친 뒤

```
python3 build.py
```

실행하면 `index.html` 안의 `/*MAT_START*/ … /*MAT_END*/` 구간이 갱신됩니다.
시대 분류는 `[헤더]`와 연도·용어 규칙으로 자동 지정되며, 규칙은 `build.py` 상단에 있습니다.

## 기능

- **모의고사**: 한능검 심화 형식. 50문항 · 5지 선다 · 100점(1점 12·2점 26·3점 12) · 선사→현대 시대순 · 80분 타이머 · 문항 이동/검토 표시 · 제출 후 채점·급수(80↑ 1급, 70↑ 2급, 60↑ 3급)
- **연습**: 범위(전체/시대/섹션/약한 섹션/오답노트)와 유형을 골라 즉시 해설
- **문제 유형**: 자료 제시 후 (가) 대상 추론 → 옳은 것/옳지 않은 것, (가)에 들어갈 대상, (가) 시기 판단, 사건 순서, 연표에서 시기 찾기 (선지는 같은 종류의 다른 대상이 한 일을 서술문으로)
- **반복 방지**: 항목별로 쓰인 키워드를 기록해 안 쓴 키워드부터 출제, 같은 문제 서명은 새 문제가 있는 동안 재출제 안 함
- **오답노트**: 문제 원문 · 내 선택 · 정답 · 틀린 이유(시대 혼동/같은 시대 혼동/연대·순서/부정형 실수/미응답) · 핵심 정리를 카드 하나에. 시대·이유·상태 필터, 섹션별 묶기, 해결 처리
- **약점 분석**: 시대·섹션별 정답률, 약한 섹션만 새로 풀기, 오답 원인, 자주 틀리는 항목, 모의고사 점수 추이, 집중 학습(검색)
- **내 문서**: 붙여넣은 글을 규칙으로 문제화 (AI 기능은 Claude 환경에서만 표시)
- 기록은 브라우저 localStorage에 저장됩니다.
